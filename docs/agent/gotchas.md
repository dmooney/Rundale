# Gotchas

- **Module ownership**: All shared game logic lives in the leaf crates under `parish/crates/` (`parish-config`, `parish-inference`, `parish-input`, `parish-npc`, `parish-palette`, `parish-persistence`, `parish-world`, `parish-types`). `parish-core` composes them; `parish-engine` re-exports via `pub use parish_core::*`. **Never** create modules in `parish/crates/parish-engine/src/` that duplicate leaf-crate logic — extend the leaf crate instead. The cli crate only contains binary-specific code: `main.rs`, `headless.rs`, `testing.rs`, `app.rs`, `config.rs`, `debug.rs`. See [architecture.md](architecture.md) for the full crate map.
- **Tokio + blocking**: Never use `std::thread::sleep` in async code; use `tokio::time::sleep`.
- **Rusqlite is sync**: Wrap DB calls in `tokio::task::spawn_blocking`.
- **Local inference, platform-specific**: On Linux/Windows the default is **Ollama** on `localhost:11434` (auto-installed/started by Parish). On macOS the default is **vllm-mlx** with the two-slot Qwen loadout (`localhost:8000` for Qwen2.5-14B Dialogue, `localhost:8001` for Qwen2.5-1.5B Intent/Reaction/Simulation), which requires 16 GB+ unified memory (~9.3 GB resident). Below 16 GB, prefer **BYOK cloud** (OpenRouter / Anthropic / Google) over a degraded local fallback — the small-slot-only path produces 2.96/5 Opus-blind dialogue. `Provider::recommended_for_platform()` returns the right pick for the host. Auto-launch for the base slot is wired through `VllmMlxProcess`; multi-slot spawn happens via `GameConfig::vllm_mlx_extra_slots()` → `VllmMlxProcess::ensure_slots()`.
- **Reqwest timeouts**: Set explicit timeouts on all HTTP requests.
- **Serde defaults**: Use `#[serde(default)]` for optional fields in LLM response structs.
- **Mode parity**: All modes (Tauri, CLI/headless, web server, future modes) must have feature parity. Implement shared logic in a leaf crate and re-export through `parish-core`, then wire it from every entry point.
- **Tauri IPC types**: `parish/apps/ui/src/lib/types.ts` must match Rust serde output exactly (snake_case field names).
- **Test fixtures path**: Integration tests run with cwd = crate root, so they reference `../../testing/fixtures/...` and `../../../mods/rundale/...`.
