# Graphics V2 Folder Notes

Exploratory concept art, prompts, and pipeline experiments for a possible graphical
version of Rundale. Design references, not production runtime assets. Not part of
the current mobile-first scope; read this folder only when working on background
plates or map-to-art pipelines.

The full file index, cycle-by-cycle findings, and detailed guidelines live in
[NOTES.md](NOTES.md). Read it before resuming plate work; do not load it otherwise.

## Rules

- Preserve original images; add variants with descriptive filenames. Save each
  prompt beside its generated image. Copy selected renders into this folder and
  reference them relatively; never commit generated-image cache paths.
- Write layout constraints (rivers, bridges, roads, paths, buildings) before style
  notes in environment prompts.
- Keep cross-model prompts self-contained. Do not rely on hidden context or earlier
  chat images.
- Recipe evidence needs clean context: separate subagents or fresh sessions for
  map-reading, control, prompt assembly, rendering, and audit, each receiving only
  its declared inputs. A prompt evaluated in a context that has seen failed renders
  is not recipe proof. Record any exception.
- No location-specific reusable prompts or hand-authored per-location hints.
  Map-reader notes are allowed only when generated by the same reproducible rubric
  for every location, saved, and confidence-graded.
- Choose plate scale, sprite scale, and camera first; back-calculate the map crop
  from them. Keep prompts north-up. Treat single thin map lines as plot boundaries,
  not footpaths.
- Any stone wall must pass the dry-stone rule in `irish-dry-stone-wall-reference.md`.
- Base plates are static art: no visible smoke, fog, or weather; those are runtime
  overlay layers.
- Prefer small style or material swatches over full illustrated scenes for one-shot
  tests, to avoid leaking landmarks and layouts. Use the door-fixed style crops,
  not the superseded door-clean ones (see `style-crops/door-fix-cycle-2026-06-28.md`).
