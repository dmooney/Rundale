## Current Boundary

Deliverables 1-6 now cover metadata, reusable paired prompting, live one-call
provider generation, pinned configuration, immutable full-sheet and child
provenance, and the atomic human review gate. The live Roisin pair remains
approved and promotion eligible, but has not yet been copied into runtime
assets. Approving one pair does not complete the named cast.

Deliverables 7-9 require human-approved production art for all 23 named NPCs and
the fallback. Runtime promotion, manifest coverage, screenshots, and final proof
remain separate work in deliverables 10-13.
