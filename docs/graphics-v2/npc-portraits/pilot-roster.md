## Pilot Stop Rules

- Do not continue to the full roster until all six have at least one acceptable
  candidate.
- If the batch splits into multiple incompatible styles, repair the style prompt
  before generating more NPCs.
- If age or clothing is consistently wrong, fix the art brief builder before
  generating more NPCs.
- If faces are not readable at `thumb-64`, simplify the crop and increase face
  scale before generating more NPCs.

## Contact Sheet Requirements

Each pilot contact sheet should show:

- candidate image at source size,
- `thumb-96`,
- `thumb-64`,
- NPC name, id, age, occupation,
- prompt id,
- audit verdict.
