# One-Shot Background Plate Test Protocol

Use this protocol when testing whether a prompt can turn a historic map tile
into a usable Rundale background plate in one shot.

## Cleanroom Context

Run each image-generation attempt in a fresh context/subagent.

Attach only:

- the target historic map crop/tile,
- optionally a generic OSI characteristic sheet / legend,
- optionally reproducible map-reader notes produced from that crop by the same
  clean-context rubric for every location,
- optionally deterministic preprocessing/control images produced by the same
  pipeline for every location,
- optionally one approved style reference if explicitly testing style anchoring.

Do not attach:

- previous generated plates,
- failed attempts,
- marked-up critique images,
- this thread's image history,
- UI mockups unless the test is explicitly style-reference-dependent,
- hand-authored per-location road, wall, river, building, landmark, or route
  interpretation notes that were not produced by the reproducible map-reader
  stage.

## Prompt Rules

- The prompt should be generic: use the map for layout rather than a
  hand-authored route graph.
- The reusable prompt must not include hand-authored location-specific hints. If
  the map crop alone is not reliable enough, add a reproducible map-reader note
  or control layer that is generated by the same procedure for every location.
- The map crop extent is not the output frame. The desired plate scale,
  orthographic camera, sprite scale, and named-location footprint should decide
  the rendered extent.
- North-up orientation is part of the contract: source-map north/top stays at
  final-image top. Do not rotate the ground plan for a prettier diagonal
  isometric composition.
- For production, choose the target plate scale and camera first, then
  back-calculate the historic map crop needed to cover the local target area and
  exits.
- The prompt should extract a local playable plate around the named location,
  not render the entire map tile. The map is layout evidence, not the required
  frame extent.
- Connectivity should be map-derived: included roads, lanes, yards, gates,
  field entrances, and thresholds from the local target area remain continuous
  and unobstructed.
- Interpret ambiguous linework conservatively. Single thin lines are usually
  plot boundaries, hedges, walls, ditches, or overgrown walls, not paths. Do not
  turn every boundary into a mud track.
- When using map-reader notes, preserve their confidence language. High
  confidence can guide the render strongly; medium confidence should stay
  plausible but generic; low confidence should remain ambiguous or be omitted.
- Distant churches, bridges, wells, crossroads, houses, and field systems may
  be omitted when they would force a high survey-map camera.
- Base plates should contain no visible smoke. Smoke/fog/weather belongs in a
  later composited runtime layer.
- Avoid repeatedly naming known bad artifacts in the image prompt. Prefer short
  positive physical rules, e.g. "no freestanding vertical masonry/roof-stack
  artifacts."

## Pass/Fail Review

A one-shot result is not acceptable just because it is attractive. Review it for:

- fixed 3/4 orthographic isometric / isomorphic perspective,
- north-up orientation: source-map top remains final-image top,
- local playable target-site crop rather than a regional overview,
- one stable ground plane,
- no horizon, sky, atmospheric distance, vanishing point, drone view, or flat
  top-down map view,
- included local roads/lanes/yards/entrances remain continuous and open,
- ambiguous single lines are rendered as boundaries rather than extra paths,
- roads read as matte muddy tracks, not streams,
- gates/openings visible at boundaries,
- door thresholds connected to yards or paths,
- no road/lane blocked by wall, hedge, tree, building, prop, or livestock,
- no dead-end decorative path fragments,
- no invented water features,
- no visible smoke or smoke wisps,
- no freestanding roof-stack/masonry artifacts,
- no UI, text, labels, signs, map pins, survey numbers, copied map symbols, or
  watermark.

For batch production, require at least two independent cleanroom generations on
the same prompt/map to pass these checks before trusting the prompt wording.
