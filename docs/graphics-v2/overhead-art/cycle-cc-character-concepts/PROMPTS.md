# Cycle CC Prompt Set

All prompts used built-in image generation. The visible Cycle CB `B no legend`
overhead watercolor map tile was provided as the style and scale reference.

## A: Integrated Miniatures on Map

```text
Use case: stylized-concept
Asset type: Graphics V2 overhead gameplay character concept art
Input image: the visible B no-legend overhead watercolor map tile is the style and scale reference for terrain, line quality, palette, and playable overhead camera.

Primary request: Brainstorm visual concepts for the player and NPCs walking on this overhead watercolor map. Create a concept sheet showing many tiny top-down 1820 rural Irish human miniatures placed directly onto a similar overhead map surface.

Scene/backdrop: overhead hand-painted rural Irish map tile: pale lane, farm buildings as roof footprints, gardens, trees, hedges, watercolor fields. Use the same muted moss, straw, parchment, raw umber, warm grey, black-brown ink style as the reference.

Subject: 12 to 16 tiny playable-scale people seen from directly overhead, distributed around roads, yard, garden edge, and woodland margin. Include a player character and varied NPC archetypes: shawled woman, farmer in cap, child, older laborer, priest-like dark coat, shopkeeper, tenant woman with apron, messenger, herder, and a few neutral villagers. They should be small but readable as people, not icons pasted on top.

Style/medium: miniature ink-and-watercolor figures, simple top-down silhouettes with a few tiny clothing color accents, soft hand-painted edges, no heavy outlines. Characters should feel painted into the map surface but still pop enough for gameplay.

Composition/framing: one large overhead concept sheet, no UI, no labels, no text, no captions. Show different scale/readability treatments in the same sheet: some as tiny full-body miniatures, some as cloak/hat silhouettes, some with subtle pale halos or tiny shadows/washes. Keep all figures flat overhead, not 3D, not isometric.

Constraints: figures must remain tiny relative to roads and buildings; no oversized portraits; no side-view characters; no frontal faces; no sprite-sheet grid; no words; no name tags; no speech bubbles.

Avoid: modern clothing, fantasy armor, cartoon chibi heads, 3D board-game miniatures, photorealism, labels, text, UI panels, giant selection rings, heavy drop shadows, animals, carts, smoke.
```
