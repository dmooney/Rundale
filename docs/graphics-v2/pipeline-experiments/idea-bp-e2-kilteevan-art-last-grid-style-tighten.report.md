# BP E2 Art-Last Style-Tighten Report

## Verdict

Pass as the preferred BP visual candidate. E2 edits E1 directly, keeping E1's
projection/crop/topology while pushing the finish closer to the original
illustrated parish notebook.

## What Worked

- The wash is lighter and less uniformly sepia than E1.
- More parchment shows through the grass, roads, walls, and roof planes.
- Roads have more pale muddy scumble and less clean board-game finish.
- Buildings retain fitted plank doors and threshold reads.
- The E2 grid-check overlay still shows the main road, right road, garden rows,
  roof ridges, and wall edges sitting in shallow parallel projection families.
- No visible grid, UI, labels, people, animals, smoke, chimneys, water, or
  invented landmarks were introduced.

## Caveats

- The garden/orchard block remains the weakest area: it is softer than BO/E1
  but still more regular and bordered than the original notebook style.
- E2 is a bounded edit from a prior generated plate, not a fresh recipe proof.
- Some local garden rows are painterly enough to pass style, but not yet soft
  enough to settle the wall/path/planting semantics problem.

## Use

Use E2 as the current BP visual target for "perspective first, art last." Keep
E1 nearby as the stricter projection reference. The next recipe-level test
should apply this ordering to a fresh source/control stack, with the hard grid
or grid-check used as a constraint rather than a visible output layer.
