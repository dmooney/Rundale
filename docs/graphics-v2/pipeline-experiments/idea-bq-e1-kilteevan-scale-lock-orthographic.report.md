# BQ E1 Scale-Lock Orthographic Report

## Verdict

Partial pass. BQ E1 directly addresses the user's constant-scale critique: the
top/north tree row no longer reads as a miniaturized distant background in the
same way BP E2 did. It is a useful grid-direction signal, but not a final visual
target.

## What Improved

- Far/top tree crowns are much closer to near/mid tree scale.
- The top edge reads more like playable map ground and less like a scenic
  background strip.
- The low oblique camera angle mostly survives.
- The fitted plank doors and no-chimney discipline mostly survive.
- The constant-scale marker overlay is a better audit than the old line-only
  grid.

## Regressions

- Vegetation became denser and more regular.
- The garden/orchard block became cleaner and more diagrammatic.
- Road/wall/garden boundaries hardened again.
- The whole plate reads a little more like a controlled board than BP E2's
  lighter notebook wash.

## Use

Treat BQ E1 as evidence that scale drift can be corrected, not as the next
production target. The important output of this cycle is the scale-lock audit:
any future "isomorphic" candidate should pass both the parallel-line grid and
the constant-size marker check before style polish continues.
