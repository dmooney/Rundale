## Classes Not Marked

- Unfenced path / track: no target candidate resembles the YES examples more than the NO examples. The single bold dotted chains fit administrative/survey boundaries, single thin lines fit field/enclosure boundaries, and paired solid edges fit road/lane corridors.
- Bridges, footbridges, ferries, fords, canals, railways, tunnels, quarries/gravel pits, wells/springs/pumps, contours, cliffs, slopes, flat/cropping rock, marsh, rough pasture, named public buildings/churches, parks, bays/harbours, benchmarks/altitudes, and antiquity symbols: no reliable visible match in this crop.
- Orchard as a separate label: the planted enclosure may include orchard/planting-like symbols, but there is no reliable separate printed orchard label or distinct class beyond the planted/mixed enclosure and tree-symbol classes.
- Rough vegetation is not applied to the regular planted enclosure because that candidate more closely matches the planted/mixed YES examples than the rough-vegetation YES examples.
