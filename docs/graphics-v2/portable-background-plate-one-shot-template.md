# Portable Background Plate One-Shot Template

This is the cleanroom prompt template for the target workflow:

```text
historic map tile + legend interpretation + prompt = one usable background plate
```

Use this in a fresh image-generation session with no prior failed renders in
context. Attach only:

1. the historic map crop/tile,
2. optionally a generic OSI characteristic sheet / legend,
3. optionally a deterministic preprocessing/control image generated by the same
   pipeline for every location,
4. optionally a single approved style reference if the model needs visual style
   anchoring.

Do not attach previous failed/generated plates when testing one-shot behavior.
Do not attach hand-authored per-location interpretation notes.

Generated control images are aids, not truth. If a deterministic or generated
preprocessing/control image contains a continuous wall, hedge, road, path,
seam, crop row, or vegetation chain that is absent from the raw map crop or
aligns with a cleaned/suppressed administrative boundary, the raw/cleaned map
must veto it. Treat top-down control boundaries as symbolic unless corroborated
by the original map.

When possible, prefer deterministic/literal controls over freehand generated
top-down plan controls. A useful control should preserve crop extent and feature
uncertainty: roads, building marks, planted regions, tree masses, open fields,
and suppressed-admin/no-data areas. It should not beautify the scene, choose a
prettier crossroads composition, complete uncertain enclosures, or redraw
ordinary parcel lines as confident walls.

Style-reference hygiene is part of the recipe. If a style reference is used, it
must be an approved crop with no labels, UI, people, animals, smoke, churches,
bridges, water, carts, loose props, chimneys, or partial doorless buildings.
Prefer exactly-one-building references where the whole visible walkable building
has a readable doorway and threshold. Reject crops that only fix the main house
while leaving a foreground/background building fragment without a door.

## Prompt Template

```text
CREATE A SINGLE USABLE BACKGROUND PLATE
Create one finished 16:9 background plate for a historical isometric game. The output is a clean illustrated environment layer only: no UI, no text, no labels, no signs, no map pins, no icons, no dialogue panels, no selection rings, no minimap markers, no visible smoke effects.

The plate must be usable for character movement. A 2D character sprite should be able to walk on the roads, lanes, yards, gates, thresholds, and paths without perspective drift or occlusion problems. The top priority is a fixed walkable 3/4 orthographic isometric / isomorphic game perspective.

TARGET
Target site: the centered or otherwise clearly framed named place/building
group in the attached map crop.
Region/time: rural County Roscommon, Ireland, around 1820.
Primary map reference: the attached historic Ordnance Survey map crop/tile.

NO LOCATION-SPECIFIC HINTS
Do not rely on any hand-authored interpretation of this specific place. Infer
roads, lanes, boundaries, buildings, planted areas, trees, water, and landmarks
from the attached map crop, generic map legend, and any supplied deterministic
control image only. Do not assume a described route graph. Do not assume any
specific exit direction, named landmark, road class, river, wall, or building
arrangement unless it is visible in the supplied map/control imagery.

MAP EXTENT IS NOT THE OUTPUT FRAME
The attached map crop may be wider or narrower than the correct game plate.
Do not let the arbitrary map zoom determine the rendered composition. The
desired output scale and fixed 3/4 orthographic camera determine the plate
extent; the map only supplies source geography.

- Choose the playable camera, sprite scale, and named-location framing first.
- Use only the subset of the map needed for that plate.
- If the supplied map crop is too wide, crop inward mentally and render the
  named site's local area.
- If the supplied map crop contains distant landmarks, treat them as source
  context, not required output content.
- In a production pipeline, the ideal map crop can be back-calculated from the
  desired camera angle, plate scale, sprite scale, and named-location footprint.

NORTH-UP ORIENTATION LOCK
The generated plate must keep the historic map's geographic orientation.

- Geographic north / the top of the source map stays at the top of the final
  image.
- East stays to the right, south stays at the bottom, and west stays to the
  left.
- Do not rotate the ground plan for a prettier diagonal composition.
- Do not rotate the road network 45 degrees around the scene.
- The 3/4 game feel comes from orthographic oblique pitch and building
  extrusion, not from spinning the map.
- Roads, lanes, enclosures, and building groups should keep their source-map
  relative compass directions after being lifted into the game plate.

STYLE LOCK
The image should look like an illustrated historical parish notebook world layer, not a realistic aerial landscape. Use:

- hand-inked watercolor over parchment
- sepia/dark-brown ink outlines
- visible pen hatching
- soft watercolor washes
- muted moss and olive greens
- cream limewashed walls
- gray slate and dark thatch where historically plausible
- ochre-brown matte mud roads
- dull wet-earth puddles only, small and broken
- graphic field boundaries
- simplified readable trees
- crisp silhouettes for buildings, gates, walls, roads, paths, yards, and orchard rows
- charming handmade historical illustration
- readable 2.5D game-board terrain

Do not over-render grass, roofs, stones, or fields into photographic detail. Use broad watercolor shapes plus ink texture. If realistic prettiness conflicts with readable illustrated game terrain, choose readable illustrated game terrain.

CAMERA LOCK: FIXED ORTHOGRAPHIC ISOMETRIC / ISOMORPHIC
This is non-negotiable.

- Use a fixed 3/4 orthographic isometric game camera.
- Camera pitch: low oblique 3/4, around 20-30
  degrees downward from horizontal.
- Do not use a steep 60-80 degree bird's-eye angle.
- Do not use a 45 degree or steeper survey-map angle if it makes walls into
  thin slivers.
- Preserve north-up map orientation; do not rotate the ground plan around the
  scene.
- Show rooftops plus two wall faces on buildings.
- Every important building should show readable wall height, door placement,
  and windows on at least one visible facade.
- Visible wall/facade area on important buildings should be at least roughly
  half the visible roof area.
- Visible wall/facade height should feel substantial, not a thin sliver below
  the roof.
- Doors, yard-facing thresholds, and front wall planes must be readable
  gameplay surfaces.
- Main building walls should read as vertical playable panels, closer to a
  compact diorama or isometric RPG scene than an aerial map.
- Main doorways should be large enough that a small character sprite could
  stand in front of them without covering the whole building.
- At least one main facade should face the viewer as a readable wall plane with
  a clear door, windows, lintel/threshold, and wall height. It should not be a
  narrow roof-edge strip.
- A human character sprite should read as roughly door-sized: smaller than a
  doorway, but large enough to stand at a threshold without becoming a map pin.
- Gates, wall openings, and doors should be vertical objects/panels, not tiny
  top-down ticks.
- Keep all walkable surfaces on one stable ground plane.
- Keep parallel edges parallel.
- Do not use a vanishing point.
- Do not use lens distortion.
- Do not use drone-photo perspective.
- Do not use high-altitude aerial survey perspective.
- Do not use top-down flat map perspective.
- Do not use steep bird's-eye perspective.
- Do not use cadastral map / estate survey zoom.
- Do not use cinematic foreground-to-background scale shift.
- Do not include a horizon line.
- Do not include sky.
- Do not include atmospheric distance.
- Do not shrink upper-frame objects because they are "far away"; this is orthographic.
- Roads of the same class stay roughly the same apparent width everywhere.
- People, doors, gates, carts, and animals keep approximately the same scale anywhere on the ground plane.
- If the roofs dominate and the walls read as narrow outlines, the camera is
  too high; lower the camera and crop closer before finalizing.

Think of the scene as painted on an invisible isometric navigation plane. The grid is not visible, but the geometry behaves as if it is there.

PLAYABLE-HUB CROP AND SCALE
The map supplies layout, but the image should be a playable location plate, not
a distant survey of the whole district.

- Crop/zoom to the named location and its immediate connecting roads/lanes.
- Target-site extraction is required. First identify the named location and
  extract a local playable scene around it; do not render the entire map tile.
- The focal location should be large enough that doors, gates, yard edges, and
  path entrances are readable.
- The named place, its yard/core enclosure, and immediate access lanes should
  occupy roughly the central 60-80% of the image width and 55-75% of the image
  height.
- The named site should read first at thumbnail size; surrounding context
  should read second.
- Include enough surrounding roads and fields to understand exits, but do not
  zoom so far out that buildings become tiny map tokens.
- Show only the immediate local network: the target yard/core, enclosing
  boundaries, adjacent planted/field areas, and the clear map-visible roads or
  lanes exiting the frame.
- Do not invent a web of extra paths. When a map mark is ambiguous, treat it as
  a boundary rather than a road.
- Open fields are edge context. Do not let empty field surfaces dominate the
  frame; crop them away when they compete with the named site.
- A character sprite should feel like it could stand at a door, gate, lane
  junction, or yard center without looking enormous.
- If the map crop includes distant context, simplify or crop that context rather
  than forcing the whole map crop into the plate.
- Distant churches, bridges, wells, crossroads, field systems, and unrelated
  houses may be omitted entirely when they are outside the named site's
  immediate playable area.
- Prefer a playable hub view over a complete cartographic overview.
- Do not fit the whole historic crop into the output. The map is a layout
  source, not a required full-frame composition.
- Do not show a regional overview. Do not show a complete survey of all roads
  and landmarks in the crop.

WALKABILITY CONTRACT
Preserve a clean invisible navigation mesh derived from the map. Do not invent a
separate route graph; use the attached map's roads, lanes, yards, entrances,
and boundaries as the layout source of truth.

1. Stable ground plane.
   - Roads, lanes, yards, gates, field entrances, churchyard paths, orchard paths, and thresholds share one coherent isometric ground plane.
   - Do not change camera angle between foreground and background.

2. Map-derived connectivity.
   - Every road or lane included from the local target area remains continuous
     in the plate.
   - Every included road or lane that enters the image from an edge continues
     naturally into the scene or out another edge, following the map.
   - Every mapped approach lane reaches its mapped building group, yard, gate, or destination.
   - Every mapped yard, courtyard, churchyard, orchard gate, farm entrance, or building threshold connects to the adjacent road/lane network implied by the map.
   - If an included lane continues beyond the local target crop, show it
     continuing cleanly off-frame.
   - Do not add isolated decorative paths that are not implied by the map.

3. Clear navigation surfaces.
   - Keep road centers and yard centers open.
   - Keep intersections open.
   - Keep gates visible.
   - Keep door thresholds connected to yards or paths.
   - Do not let tree canopies hide route centers, gates, or intersections.
   - Props, carts, barrels, livestock, people, tools, and walls sit beside paths, not across paths.

4. No dead path fragments.
   - No path stops at a random field center.
   - No lane disappears into a hedge without a visible gate/opening.
   - No route terminates behind a single tree or building.
   - No wall, hedge, fence, or ditch crosses an active road without a visible gate or gap.

5. Sprite-friendly scale.
   - Roads and yards are wide enough for a small character sprite.
   - Important walkable areas remain visible after UI is later placed over the plate.
   - If a route exits the frame, show it clearly continuing off-frame.

MAP TRANSLATION RULES
Use the attached historic map as ground-plan truth, not as style.

1. Building marks.
   - Dark solid or hatched rectangles on the map become physical 1820 rural Irish buildings.
   - Render whitewashed stone, rough stone, thatch, slate only where plausible, dark windows, timber doors, sheds, byres, cartsheds, barns, and modest farm courts.
   - Do not reproduce black map marks as graphic symbols.

2. Roads and lanes.
   - Double or parallel line marks become continuous muddy cart roads or lanes.
   - Wide roads with boundary lines on both sides become walled, hedged, or
     ditched roads/lanes.
   - Preserve road/lane connectivity.
   - Keep roads matte brown/ochre, with small dull puddles only where needed.
   - Roads must not look like streams.

3. Dotted, pecked, dashed, or broken lines.
   - These usually represent hedges, low walls, ditches, property edges,
     townland/parish boundaries, field boundaries, overgrown walls, or other
     non-walkable edges.
   - If a line forms an enclosure or field edge, render a boundary, not a path.
   - If a line clearly connects route-to-route and is road-like on the map,
     render a narrow lane or track.
   - Do not turn every dotted boundary into a footpath.
   - Do not draw mud tracks parallel to every boundary.

4. Single thin lines.
   - Single thin solid lines are plot lines, field boundaries, walls, hedges,
     ditches, or overgrown stone walls by default.
   - They are not roads unless the map clearly shows road width, route
     continuity, or an entrance/exit.
   - Render them as boundaries with occasional gates/openings only where real
     roads pass through.
   - Do not convert single plot lines into decorative footpaths.

5. Trees.
   - Round tree symbols become rounded broadleaf trees.
   - Triangular/conical tree symbols become darker conifers.
   - Mixed tree marks become mixed planting.
   - Keep open fields open; do not turn the whole tile into forest.
   - Keep trees beside routes, not in route centers.

6. Planted enclosures.
   - Ordered rectangular planted areas become orchards, kitchen gardens, nurseries, or ornamental grounds depending on context.
   - Use straight internal divisions, rows of small trees or beds, and a visible gate.

7. Survey notation.
   - Survey numbers, altitude numbers, acreage figures, triangle marks, printed labels, and map typography are not in-world objects.
   - Do not draw them in the final plate.

8. Scan texture.
   - Pale stipple, paper grain, halftone dots, and scan noise are not terrain details.
   - Do not turn them into gravel, flowers, snow, ash, cobbles, or dotted ground.

9. Modern viewer overlays.
   - Ignore modern colored icons, gold markers, map pins, labels, and app overlays.
   - Render only physical features implied by the historical map.

LOCATION-SPECIFIC LAYOUT
Translate this specific map tile into the isometric game plane. Keep this
section generic enough to reuse across locations. Use only observations from
the map tile, generic legend, or deterministic control image:

- Identify the main building group or named place in the map crop and make it the readable focal location.
- Keep the named location visually dominant. Secondary landmarks should support
  orientation, not become co-equal focal anchors.
- Secondary churches, wells, bridges, crossroads, or other landmarks should be
  edge-biased, smaller, partially cropped, or otherwise visually subordinate
  unless the named location itself is that landmark.
- Secondary landmarks should occupy less than about 15-20% of the total image
  area unless the named location itself is that landmark.
- Omit secondary landmarks entirely when including them would force a high
  overview, weaken the named location, or make the camera look like a map.
- Preserve the relative placement of roads, lanes, yards, buildings, planted
  enclosures, field boundaries, and trees in the named site's local area.
- Preserve road/lane continuity and entrances/exits that serve the named site.
- Preserve local field shapes and boundary angles around the named site,
  simplified only where needed for isometric readability.
- Convert mapped building footprints into plausible period buildings arranged around their mapped yards or lanes.
- Convert mapped planted enclosures into ordered gardens, orchards, nurseries, or ornamental grounds.
- Convert mapped church/churchyard features into physical church/churchyard
  context only when the named location is the church or the church lies inside
  the immediate local target crop; otherwise omit or crop it.
- Keep all routes, yards, gates, entrances, and thresholds walkable and unobstructed.

BASE PLATE LAYERING RULES
This is a base environment plate. Leave dynamic effects for later game layers.

- No visible smoke.
- No chimney smoke.
- No hearth smoke.
- No fog or smoke wisps.
- No dramatic weather particles.
- No UI glows, marker glows, selection rings, or attention effects.
- Lighting should be soft overcast daylight, suitable for later tinting.

ARCHITECTURE SANITY
Use plausible rural Irish 1820 building logic. Keep this simple and physical.

- Every roof sits on a complete building volume.
- No roof fragments lying on roads, walls, hedges, or fields.
- Use low fieldstone walls and hedges for boundaries.
- Gates interrupt boundaries wherever routes pass through.
- Walls do not cross doors, roads, lanes, or yard entrances.
- Avoid decorative freestanding vertical masonry/roof-stack artifacts.
- If a roof stack appears, it must be small, roof-attached, and on a substantial building only.
- Many poor thatched cabins have no proper roof stack at all; plain thatched roofs are acceptable.

NO INVENTED WATER UNLESS THE MAP CLEARLY SHOWS IT
{{WATER_RULE}}

FINAL SELF-CHECK
Before finalizing, ensure:

- Fixed 3/4 orthographic isometric / isomorphic game perspective.
- North-up orientation: source-map top is final-image top.
- Low enough pitch to show meaningful building facades.
- Important facades are not thin roof-edge slivers; doors and front walls are readable.
- The named location occupies central playable hub scale instead of becoming one tiny site in a complete map overview.
- Only local target-site roads and exits are shown; distant map context is
  omitted or pushed off-frame.
- Open fields and distant boundaries do not dominate over the named site's
  buildings, yard, gates, and immediate paths.
- One stable ground plane.
- Same visual scale across the plate.
- No horizon, sky, atmospheric distance, vanishing point, drone view, or top-down map view.
- All map-visible roads/lanes/yards/entrances are continuous and open.
- Roads stay matte muddy tracks, not streams.
- Gates/openings are visible at boundaries.
- Door thresholds connect to yards or paths.
- No route is blocked by wall, hedge, tree, building, prop, or livestock.
- No dead-end path fragments.
- No invented water features.
- No visible smoke or smoke wisps.
- No freestanding roof-stack/masonry artifacts.
- No UI, text, labels, signs, map pins, survey numbers, copied map symbols, or watermark.

Priority order:
1. fixed walkable orthographic isometric perspective
2. map-derived navigation clarity
3. correct map topology
4. illustrated parish-notebook style
5. plausible 1820 rural Irish architecture
6. beauty and detail
```
