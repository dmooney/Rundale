# Irish Dry-Stone Wall Web References

These images are saved as real-world material references for Graphics V2
prompts. Use them to show the image model what "Irish dry-stone wall" means
visually: mortarless, irregular, slabby/fieldstone construction with gaps,
uneven tops, and vegetation.

## Files

- `irish-dry-stone-wall-reference-sheet.png` — local two-image prompt reference
  sheet combining close texture and field-scale context.
- `fahee-north-dry-stone-wall-2015.jpg` — close wall texture: slabby limestone,
  dark gaps, irregular interlock, uneven top, vegetation at base.
- `inisheer-gardens-dry-stone-walls-2002.jpg` — field-scale context: irregular
  dry-stone wall networks around fields/gardens.

## Prompt Guidance

For the next Grove repair, use `irish-dry-stone-wall-reference-sheet.png` as a
material reference only. Do not copy the sky, horizon, modern house, or exact
wall layout. The target is the wall construction language: slab fragments,
mixed stone sizes, angled faces, gaps, broken tops, moss/weeds, and irregular
field-boundary rhythm.
