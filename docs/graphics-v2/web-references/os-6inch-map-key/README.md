# 6-Inch Ordnance Survey Map Key Reference

Local reference material for interpreting Irish 6-inch Ordnance Survey map
symbols in Graphics V2 map-to-background-plate experiments.

Source:

- Scoilnet, `Mapping the Past`, PDF:
  <https://www.scoilnet.ie/fileadmin/user_upload/T3U1L1.pdf>

Saved files:

- `mapping-the-past-scoilnet.pdf` — source PDF.
- `os-6inch-map-key-page-22.png` — rendered factsheet page with natural
  features.
- `os-6inch-map-key-page-23.png` — rendered continuation page with road/symbol
  key and third-edition examples.
- `os-6inch-map-key-natural-features.png` — cropped key for tree, orchard,
  rough pasture, rock, slope, structure, and bridge samples.
- `os-6inch-map-key-roads-symbols.png` — cropped key for writings, roads,
  bridges, contours, wells, and related symbols.
- `os-6inch-map-key-third-edition-examples.png` — cropped third-edition example
  sheet.
- `os-6inch-map-key-reference-sheet.png` — combined prompt/reference sheet.

Use this as a symbol-interpretation reference, not as style. The generated game
plate should still use the source crop as geometry authority and BU/concept
art as visual style authority.
