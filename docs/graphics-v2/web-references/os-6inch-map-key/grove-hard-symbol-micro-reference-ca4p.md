# Grove Hard-Symbol Micro Reference CA4P

Focused reference for the two Grove map-reading classes that remained unstable
after CA4O:

- `Unfenced path / track candidate`
- `Vegetated ditch / rough boundary strip`

Use this alongside:

- `os-6inch-map-key-reference-sheet.png`
- `grove-map-hint-examples-ca4m.png`

CA4P is a micro-reference, not a location instruction sheet. It enlarges the
positive and negative visual examples for the two hard classes so a
clean-context map reader can compare symbol shapes before annotating the target
crop.
