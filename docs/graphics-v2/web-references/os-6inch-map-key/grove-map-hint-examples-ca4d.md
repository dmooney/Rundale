# Grove Map Hint Examples CA4D

These examples are cropped directly from
`docs/graphics-v2/grove-map-target-site-crop.png` to support the clean OS
6-inch key reference. They are supplemental symbol examples, not location
instructions.

Use:

- `os-6inch-map-key-reference-sheet.png` as the clean map key,
- `grove-map-hint-examples-ca4d.png` as source-crop examples for the added
  hints,
- `os-6inch-map-key-reference-sheet-grove-examples-ca4d.png` only when a single
  combined reference image is needed.

Do not use the earlier CA4 annotated-key attempt as model input; it marked up
the legend itself and is superseded by CA4D.
