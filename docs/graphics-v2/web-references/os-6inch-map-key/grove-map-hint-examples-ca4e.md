# Grove Map Hint Examples CA4E

These examples are cropped directly from
`docs/graphics-v2/grove-map-target-site-crop.png` to support the clean OS
6-inch key reference. The labels are general symbol classes, not
location-specific instructions.

Use:

- `os-6inch-map-key-reference-sheet.png` as the clean map key,
- `grove-map-hint-examples-ca4e.png` for reviewable source-crop examples,
- `os-6inch-map-key-reference-sheet-grove-examples-ca4e.png` only when a
  single combined reference image is needed.

Do not use the earlier CA4 annotated-key attempt as model input; it marked up
the legend itself. CA4D is also superseded because it used location-specific
wording for the unfenced-path example and weaker/contaminated examples for
conifers, solid boundaries, and rough vegetation.
