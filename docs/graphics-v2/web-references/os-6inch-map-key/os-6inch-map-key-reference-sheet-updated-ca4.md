# Updated OS 6-Inch Map Key Reference Sheet CA4

Derivative of `os-6inch-map-key-reference-sheet.png`.

The original OS 6-inch key plate remains intact. The CA4 derivative adds a
right-side hint panel and numbered callouts for recurring interpretation
failures in the Graphics V2 map-reading pipeline:

- puffy circular tree symbols are deciduous trees,
- bold dotted administrative linework inside a road corridor is not terrain,
- paired light dashed linework is an unfenced road/path/track only where
  visible,
- solid enclosure lines are boundaries rather than walkable routes,
- dense tree/mark clusters can be rough vegetation, scrub, overgrown ditch,
  hedgerow, furze/whins, or rough pasture,
- dark/hatched rectangles are probable roofed structures,
- printed map labels are not in-world signs.

Use this image as a symbol-reference aid for clean-context map annotation, not
as a style reference for final background art.
