## Recommendation

**No preset swap.** The incumbent `Qwen2.5-14B-Instruct-4bit` ties
with `Qwen3.6-27B-4bit` within noise (Δ 0.08, below the 0.3 noise
floor) at half the RAM footprint (9 GB vs 17 GB). Switching to Qwen3.6
would cost roughly +8 GB peak with no measurable quality gain on this
slice.

**Don't ship Gemma-3 via vllm-mlx without a chat-template fix.** Z's
collapse is a tooling bug, not a model bug; the QAT weights are
known-good and worth re-evaluating once the template is wired
correctly.

**MoE not a clear win.** Qwen3-30B-A3B-4bit is 17 GB resident for 3B
active and lands 0.3 below the dense leaders. The headline "30B at 3B
speed" advantage doesn't show up on this dialogue slice.

**Period-prose tunes need a tighter instruction-following sleeve.**
Violet-Lyra has the voice but won't keep to a 1-3 sentence cap.
Re-evaluate only if the runtime prompt is rewritten to be tolerant of
3-8 sentence replies, or if a Gutenberg-tuned base lands with stronger
instruction tuning.
