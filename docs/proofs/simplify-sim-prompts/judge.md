One mild risk the transcript does not flag: snapshot construction is now O(N) in `all_npcs()` per Tier tick because every dispatch site builds a full `HashMap<NpcId, String>` even when only a few NPCs are in the batch. Also, the unknown-id fallback resolves to literal `"someone"` — fine for prompt fluency, but if a future caller passes a stale relationship to a now-removed NPC the LLM will see "friendly with someone" rather than an obvious bug marker; the test pinning this is good but the choice deserves a comment.
