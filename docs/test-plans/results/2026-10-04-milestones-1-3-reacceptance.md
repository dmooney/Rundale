# Spec Milestones 1–3 re-acceptance on the shared-engine line

> Issue: #2047 (Mobile Phase 5). Supersedes the `ios-port` audits #1990 and
> #1992. Recorded 2026-10-04. The gate runs below were taken at `main`
> revision `3c2345a90`; PRs #2162, #2163, #2164, #2165, and #2169 followed

This records a current verdict for every spec Milestone 1–3 requirement
(product spec §17) on the mobile line built from `main`, where the iPhone app
runs the shared Limerick engine through `limerick-mobile-ffi`. It replaces the
`ios-port` verdicts, which were proven against a mobile-only runtime
(`limerick-core/src/mobile`, `limerick-persistence/src/mobile`) that was not
carried forward.

**No physical-iPhone testing happened in this pass.** On 2026-10-04 the owner
waived physical-iPhone testing for this re-acceptance and accepted simulator
evidence ("Skip physical iPhone testing. The sim is enough."). Requirements
that the spec ties to a physical iPhone are marked **Waived (simulator
accepted)**. Every result below is a simulator, engine, or live-Endpoint
result, never a device result.
