# Canonical world sheet for the Rundale tiny world (product spec §14).
#
# This is a test oracle: limerick-engine's `world_sheet` test loads
# this mod, plays it from a new game, and fails on any contradiction.
#
# START block
#   time, location:      where and when a new game begins
# Location blocks
#   exits:               every destination reachable from the location
#   present at HH:MM:    who is present there at that time on the first day
#                        (a location with no line for a listed time is empty)
# NPC blocks (headed by first name)
#   home:                where the NPC lives and starts the game
#   knows:               the NPCs they have an authored relationship with
#   village:             the village their dialogue prompt describes
#                        (dialogue.json), which lists them, gives them a
#                        backstory, and words each relationship
#
# Every location and NPC in the mod appears here, and nothing else does.
#
# Living-world proof blocks (product spec §17 Milestone 6). Each names the
# one fact a proof uses, so a tester knows what should happen and to whom.
# GOSSIP (living-world.json)
#   fact, source:      the one initial fact, known to its source alone
#   path:              the one intended NPC-to-NPC path, source first
#   never told:        the NPCs the fact must never reach
# TASK (living-world.json)
#   giver, site:       who assigns it, and where it is advanced and completed
#   task:              the work, as the task ledger records it
#   assigned, in progress, completed, afterwards:
#                      the states it passes through and how later talk shows it
# WEATHER (engine rule: a non-farm NPC does not go outdoors in rain)
#   npc, weather:      who, and the weather that triggers it
#   in that weather at HH:MM, otherwise at HH:MM:
#                      where the NPC is at that time with and without it
# MOVEMENT (the NPC's schedule in npcs.json)
#   npc, out, back:    who, and each scheduled walk as "HH:MM from to to"
