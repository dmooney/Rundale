# Parish Notebook UI Assets

These assets are the first concrete UI atlas for the illustrated notebook shell.

- `scene-crossroads.png` lives one directory up and is the temporary full-bleed scene plate.
- SVG files here are blank, reusable frame and icon assets. Dynamic game text and the portrait thread's generated portraits should be overlaid by Svelte.
- Portrait art is intentionally not included; use `portrait-slot.svg`/`portrait-slot-selected.svg` as the target placeholders.
