# Generated Notebook UI Assets V1

These PNGs are the first saved individual asset cuts from the generated blank notebook UI sheet.

The source sheet is `notebook-ui-sheet-v1-source.png`; `notebook-ui-sheet-v1-alpha.png` is the despilled transparent version used for the crops. The crop list and intended roles are recorded in `manifest-v1.json`.

Portrait artwork is intentionally absent. Use `people-rail-v1.png` as the portrait-slot target for separately generated portraits.
