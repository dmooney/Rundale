# Verification fixture for extract-providers.
#
# Exercises the inference path end-to-end on the simulator provider so that
# the refactor (parish-inference → parish-providers) is proven live rather
# than just by unit tests.
#
# This fixture:
#   1. Confirms the active provider is the simulator (AC-9, AC-10).
#   2. Drives two NPC dialogue turns that exercise the AnyClient::Simulator
#      path through parish-providers (AC-9).
#   3. Exercises Tier 2 background simulation by advancing time (AC-8, AC-9).
#   4. Verifies the three priority lanes are all reached (Interactive via
#      the dialogue turns, Background via /wait, Batch via the second /wait).
#
# Run:
#   cargo run --manifest-path parish/Cargo.toml -p parish-engine -- \
#     --script parish/testing/fixtures/play_extract-providers.txt
#
# Or against a live server (parish-mcp-backend.sh start):
#   parish --script parish/testing/fixtures/play_extract-providers.txt
#
# Expected signals in output:
#   - "provider":"simulator" in /status JSON (AC-9)
#   - At least one "kind":"talked" turn with a non-empty "text" field (AC-9)
#   - No "error" key in any inference log line (AC-10, AC-7)
#   - /provider output includes "simulator" as current provider (AC-9)
#   - No panic or compile error (AC-3, AC-7)

# 1. Baseline — confirm simulator is active and world is reachable.
/status
/provider
/time
look

# 2. Observe NPCs at starting location.
/npcs

# 3. Interactive-lane turn: address an NPC by name.
#    This dispatches through AnyClient::Simulator via the queue worker
#    (Interactive priority lane).  The simulator must return a non-empty
#    dialogue response without error.
say hello, how are you this fine morning?

# 4. Second Interactive-lane turn: confirm the worker loop continues.
say what is the news in the parish today?

# 5. Advance time by 30 minutes — triggers Background (Tier 2) simulation
#    for co-located NPCs, exercising the Background priority lane.
/wait 30

# 6. Observe updated NPC state and world clock.
/time
/npcs
look

# 7. Advance further — triggers Batch (Tier 3) distant NPC simulation,
#    exercising the Batch priority lane.
/wait 60

# 8. Final status check to confirm no errors in the inference log.
/status
/time
look
